# 桌宠功能清单

---

## 一、宠物管理（设置页）

| 功能 | 说明 |
|------|------|
| 已安装宠物列表 | 卡片网格展示（名称 + 预览动画 + 唤醒/删除按钮） |
| 导入宠物 | 支持拖拽本地文件（pet.json + spritesheet.webp）、粘贴社区链接（petdex.crafter.run / codex-pets.net）、浏览社区画廊、本地文件选择 |
| 导入预览 | 展示 idle 动画循环播放 + 宠物名称输入 |
| 删除宠物 | 从 `~/.aichat/pets/` 移除 |
| 默认宠物选择 | 下拉选择启动时默认显示哪只 |
| 启动自动唤醒 | 开关，aichat 启动时自动显示宠物 |
| 宠物缩放 | 滑块 0.5x ~ 2x |
| 位置预设 | 屏幕右下 / 屏幕左下 / 自定义 |

## 二、桌面悬浮窗（宠物本体）

| 功能 | 说明 |
|------|------|
| 独立透明窗口 | 192×208 无边框透明窗口，浮动在所有普通窗口之上、系统 UI 之下 |
| 精灵图动画渲染 | Canvas 2D 逐帧播放 spritesheet，支持指定行号 + FPS 控制 + 循环/单次 |
| 点击穿透 | 透明区域点击直达下方应用，仅宠物非透明像素响应交互 |
| 默认位置 | 屏幕右下角，距边缘 20px |
| 拖拽移动 | 手动拖到任意位置，松手时距边缘 ≤ 20px 自动吸附 |
| 位置记忆 | 记住上次位置，重启恢复 |
| 屏幕跟随 | 主窗口跨屏时宠物自动迁移到对应屏幕 |
| 全屏检测 | 检测到游戏/视频/PPT 全屏 → 自动隐藏；退出全屏 → 恢复显示 |
| 生命周期绑定 | aichat 启动→宠物显示 / 最小化到托盘→宠物继续显示 / 彻底退出→宠物关闭 |

## 三、状态机（6 个核心状态）

| 状态 | 触发条件 | 宠物表现 |
|------|----------|----------|
| **IDLE**（待机） | 默认态，无对话交互 | 呼吸浮动 + 眨眼 + 眼神追踪鼠标 |
| **ATTENTION**（关注） | 用户开始输入消息 | 打招呼/看向用户方向 |
| **THINKING**（思考） | AI 开始推理 | 皱眉、来回踱步、头顶省略号气泡"思考中…" |
| **SUCCESS**（完成） | 回复生成完毕 | 庆祝跳跃 + 撒花粒子，气泡显示摘要（3.5秒后回 IDLE） |
| **ERROR**（出错） | 请求失败/超时 | 沮丧冒烟（3.5秒后回 IDLE） |
| **WAITING**（等待确认） | 需要用户权限审批 | 头顶气泡显示操作按钮，如"需要修改 3 个文件，确认吗？[批准] [拒绝]" |

## 四、渐进式 Idle 行为

| 时间 | 行为 |
|------|------|
| 0 ~ 30秒 | 正常 idle（呼吸 + 眨眼 + 眼追鼠标） |
| 30秒 ~ 2分钟 | 随机小动作（挠头、东张西望） |
| 2分钟 ~ 5分钟 | 打哈欠、伸懒腰 |
| 5分钟以上 | 打盹/睡觉，💤 气泡，点击唤醒 |

## 五、用户交互

| 交互 | 行为 |
|------|------|
| 鼠标悬停 | 宠物看向鼠标，仅非透明区域响应 |
| 单击 | 弹出快捷菜单（切换会话 / 查看状态 / 收起） |
| 双击 | 呼出 aichat 主窗口 |
| 右键 | 上下文菜单（切换宠物 / 设置 / 休眠） |
| 拖拽 | 移动位置到任意屏幕位置 |
| 拖入文件 | 触发文件上传到当前对话 |
| 气泡点击 | 跳转到 aichat 主窗口对应会话 |

## 六、气泡交互

| 类型 | 内容 | 交互 |
|------|------|------|
| 状态气泡 | THINKING 显示"思考中…"，SUCCESS 显示摘要 | 自动消失（10秒） |
| 权限气泡 | 操作描述 + [批准] [拒绝] 按钮 | 点击按钮直接响应，不切窗口 |
| 可点击气泡 | 任务完成摘要 | 点击跳转 aichat 主窗口对应会话 |
