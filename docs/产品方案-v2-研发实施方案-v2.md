**文件**: `src/components/SettingsArea.tsx`

- `activeTab` 类型：`'model' | 'memory' | 'profile'` → `'model' | 'memory'`

  ```tsx

  ┌──────────────────────────────────────────────┐
  │  记忆设置                                     │

  │  个人信息                                    │

  └──────────────────────────────────────────────┘
  ```

#### 2.2 修改后端 Profile API

**文件**: `server/src/routes/profile.ts`
- GET → 返回 `{ content: string }`（固定 key `"personal_info"`）
- PUT → 保存 `{ content: string }`
- DELETE → 废弃或改为清空
- 数据库表结构不变，旧 KV 数据直接丢弃

**文件**: `server/src/services/UserProfileService.ts`
- `getAll()` → `get(): string`
- `set(key, value)` → `save(content: string)`
- `buildProfileSection()` 保持不变

#### 2.3 修改前端 Profile API

**文件**: `src/services/api.ts`
```typescript
// 旧 → 新
export const profileApi = {
  list: () => ...       →  get: () => request<{ content: string }>('/profile'),
  update: (data) => ... →  save: (content: string) => request('/profile', { method: 'PUT', body: JSON.stringify({ content }) }),
  remove: (key) => ...  →  （删除）
};
```

#### 2.4 更新 Sidebar + App.tsx 类型（最终态）

- 删除 `User` 图标导入

**文件**: `src/App.tsx`
